# Backlog

Work that is known but not scheduled yet. A line leaves a backlog file when it is paid (its row says when) or when it becomes a step of a phase or a decision in `../design/`.

| File | Holds |
|---|---|
| [tech-debt.md](tech-debt.md) | the technical debt of the project, `TD-nn`: every shortcut, gap or postponed piece, with why, where and when to pay; a new one is added in the same commit as the shortcut |
| [library-gaps.md](library-gaps.md) | the gaps of the language found by writing the standard library in Eve, `G-n` |
| [ideas.md](ideas.md) | ideas that are not designed yet, and reserved words without a design |
| [tutorial.md](tutorial.md) | wording and layout items of the tutorial pages (`TB-n`), moved from `design/issues/` |
| [tools-tech-debt.md](tools-tech-debt.md) | the debt of the editor plugins in `tools/` |
| [vscode-plugin.md](vscode-plugin.md) | the to-do list of the VS Code plugin and the GitHub colors |
| [evedb-ideas.md](evedb-ideas.md), [evedb-ideas-review.md](evedb-ideas-review.md) | ideas for evedb and their review |
| [evetx-requests.md](evetx-requests.md) | the author's requests for evetx |
| [evetx-status.md](evetx-status.md) | the state of the work on evetx for level 6 |
