Eve → PostgreSQL protocol → evedb (DuckDB) on port 5432

Each button sends an Eve script to the machine (POST /rpc, method vm.run). The script opens database.connect("shop"); eve.cfg says postgres://eve:demo@127.0.0.1:5432/shop, so the Eve driver for PostgreSQL logs in to evedb with md5 and runs the SQL there.
