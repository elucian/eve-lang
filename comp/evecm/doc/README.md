# evecm: the common part

`evecm` is the module that every other part of Eve uses: the compiler (`evecp`), the runtime (`evevm`), the database layer and the user interfaces (`evetx`, `eveux`). It holds Zig code only and depends on nothing but the Zig standard library. It is not a program: it is built into each of the others.

## What it holds

| Area | Content |
|---|---|
| Values | the value of Eve and the objects it points to (lists, maps, objects, classes, functions), the error codes, the heap with reference counting and a tracing collector |
| Numbers and time | exact decimals, instants and durations |
| Text | Unicode normalization (NFC), the line editor and the raw keyboard mode of the prompt |
| Data | CSV and JSON text, connection URLs |
| Machine | the keys of `eve.cfg`, the socket folder, the exit codes, the wire format (JSON-RPC answers, HTTP helpers, the client calls to a machine) |
| Interfaces | `Host` and `Data`: the contract between the runtime and the database layer, so neither imports the other |
| Editors | the parts of the editors that need no screen: the text buffer, the scanner and colors of Eve and SQL, the keyword list, projects, regular expressions, the data grid, the link to a machine, the user cache |
| Version | the version of Eve, given by the build |

## For developers

The unit tests of `evecm` run with the others: `zig build test` from the root of the source tree. The keyword list of the editors is generated from the specification (`python comp/evetx/gen_keywords.py`); the Unicode tables are generated by `python script/gen_nfc.py`. Neither is edited by hand.
