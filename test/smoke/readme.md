# test Smoke

The quick check that the machine and the language are sane (D-134, D-135). It runs in less than a second and does not depend on the tests of the levels. It is the portable part: any implementation of Eve should pass it first.

Each script is a driver with small functions and very simple `expect` lines, one feature each. A failed `expect` is an absurd and obvious error. Add a line when a bug is found that a smoke script should have caught.

| Script | Feature |
|---|---|
| `topology.eve` | the shape of a program: driver, process, function, procedure, constant, `recover` and `finalize` in order |
| `logic.eve` | True and False, the tables of `and`, `or`, `xor` and `not` |
| `numeric.eve` | zero, one, the extreme integer, operators, literals, zero values |
| `string.eve` | the empty string, concatenation, comparison, escapes |
| `collection.eve` | empty collections, zero values, indexes from 1, literals |
| `variables.eve` | `new`, `set`, `let`, share and copy, scopes |
| `constants.eve` | `set`: typed or not, from an expression, global and local; never changed |
| `constant_assign.eve` | assigning a constant is a compile error, nothing runs |
| `operators.eve` | precedence, compound forms, list operators, ranges, `in`, `is`, `=~` |
| `control.eve` | `if`, `while`, `loop`, `for`, `match`, `break`, `skip`, labels |
| `subprograms.eve` | functions, procedures, arguments, `@`, vararg, recursion, lambdas, closures |
| `errors.eve` | jobs with `resume`, the error codes, `defer`, `exit`, `over`, `finalize` |
| `types.eve` | `type`, `is`, conversions, optional, variant, ordinal |
| `objects.eve` | class, constructor, methods, inheritance, extension, share and copy |
| `placeholders.eve` | names, literals, expressions, formats, code points, entities, braces |
| `project/` | one module, one aspect, one apply: import, life cycle, `safe` and `Atomic` |

Run it with `python script/runtest.py smoke`.
