# test Level 6

This level tests the Eve machine and the server: setup, remote control, serve, services and routes, the API for AI (version 0.5, design/decision/level6.md). A test is a pair of projects, a client and a server, on localhost with different ports.

A test is a project folder (D-073): `test/level6/f01_feature/` holds the driver `f01_feature.eve` and its `expect.json`. Test names start with `f`. No test is written yet: the features of this level are drafts.

## Tests

The tests and the result of the last run are in `level6.json` of this folder (written by the test runner after every run).
