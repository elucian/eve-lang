# test Level 3

This level tests modules and imports, local libraries, classes and methods (version 0.2, `plan/decision_level3.md`). The data language is level 5 (D-125). The level starts with modules and imports (c01 to c09, `semantics/modules.md`), then the local libraries, then classes and methods (c10 to c17, D-122, D-123). A test is a folder when it needs a project (`lib/`, `asp/`), a file otherwise (D-124); test names start with `c`. A project folder may hold more drivers, `c01_test1.eve`, `c01_test2.eve`, ...: variations that reuse the same modules (D-133).
