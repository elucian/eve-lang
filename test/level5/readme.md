# test Level 5

This level tests version 0.4: the generic functions, procedures, methods and processes and the overloading of subprograms (D-147 to D-149, `spec/syntax/declarations.md#generic-subprograms-and-overloading`), then the data language and the database layer: connections, query streams, bulk loads, transactions, checkpoints, admin commands (plan/decision_level5.md). Database tests run against the Eve database (SQLite), so they need no database server.

A test is a single file (`e01_generic_function.eve`) or a project folder (D-073): `test/level5/e04_generic_process/` holds the driver `e04_generic_process.eve` and its `asp/`; the expectations are in the `/*@expect*/` block of the driver. Test names start with `e`. Tests e01 to e15 are written first (2026-10-09): they fail until the VM has the generic subprograms and overloading. The compile-error tests check the message with `contains`, so a VM that does not know the syntax yet does not pass them.
