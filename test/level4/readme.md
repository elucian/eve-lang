# test Level 4

This level tests parallel processing and streams, and generics and traits (D-138): parallel groups, channels, streams, region memory (version 0.3, plan/decision_level4.md). Tests are deterministic: the same input gives the same output and the same errors in the same order.

A test is a single file (`d17_job_spawn.eve`) or a project folder (D-073): `test/level4/d04_parallel_group/` holds the driver `d04_parallel_group.eve` and its `asp/` and `lib/`; the expectations are in the `/*@expect*/` block of the driver. Test names start with `d`. The specification is `spec/semantics/multitasking.md` and `spec/syntax/declarations.md#traits-and-generic-classes` (D-140 to D-145). Tests d04 to d26 were written before the VM (TDD, 2026-10-08): they fail until the VM implements them. A compile-error test also checks the message (`stderr`), so it passes only for the right error.
