EVE-TX  Shortcuts
=================

Menu
  F10, Ctrl+Enter     open the menu bar
  Alt + letter        open a menu: F E S R M W H
  Left, Right         next menu
  Up, Down, Enter     choose a command, Esc closes

File
  Ctrl+O              open project (the list of known projects)
  Ctrl+Shift+O        open folder (browse and import a folder as a project)
  Ctrl+N              new file
  Ctrl+S              save
  Ctrl+Shift+S        save as
  Ctrl+W              close the window (tab)
  Ctrl+Q              quit

Edit and search
  Ctrl+H              replace (Tab between the fields)
  Ctrl+F              find text (Enter next match)
  Ctrl+P              find file (Up, Down, Enter opens)
  Ctrl+G              go to line (42 or 42:7)
  F7                  query (later)

Selecting and copying
  Shift + arrows, Home, End, PgUp, PgDn   select text
  Ctrl+Left, Ctrl+Right   move one word; with Shift they select it
  Ctrl+A              select all
  Ctrl+C, Ctrl+X      copy, cut (the system clipboard gets the text too)
  Ctrl+V              paste (a paste made by the terminal works as well)
  Mouse               click puts the cursor, drag selects, Shift+click extends

Editor view
  Edit > Show hidden characters   middle dot = space, arrow = tab, return sign = line end
  Edit > Wrap       wrap long lines (no horizontal bar; the vertical bar gets ^ and v
                    buttons: half a page). Without wrap the horizontal bar has
                    < and > buttons: ten columns each
  Click on a line number (or the space next to it)   set a breakpoint;
                    click on the red circle to remove it. F9: on the cursor line

Run and debug
  F5                  run the .eve file: `run <file>` is typed in the Console prompt
                      and starts after 3 seconds (Enter: now, Esc: cancel,
                      typing keeps the text and stops the countdown)
  F6                  check the syntax: `--check <file>`, the same way
  F9                  breakpoint
  F8, F11, Shift+F11, Shift+F5   debugger (later)

Machines
  Alt+1               local machine
  Alt+2, Alt+3        remote machines (later)

Windows and panels
  Alt+Left, Alt+Right previous / next panel: Tree, Main, Tools (Shift+Tab: next)
  Ctrl+Tab            next window of the Main panel, or next tab of the Tools panel
  Ctrl+PgUp, Ctrl+PgDn  previous / next window or tab
  Ctrl+1 .. Ctrl+9    window number 1 to 9
  Layout: over a border between panels the pointer is a double arrow and the
                      border turns amber; press and drag it. Three seconds after
                      the mouse is released the layout freezes by itself
  Ctrl+L              layout modify (WINDOW > Layout modify): drag the borders or
                      use the arrow keys (Left, Right: Tree Panel width; Up, Down:
                      Tools Panel height)
  Ctrl+F              layout freeze (in layout modify; Esc and Enter too)
  The buttons + and x of a panel maximize and hide it;
  Window > Tree Panel, Main Panel, Tools Panel show it again

Console
  Enter               run `eve <line>`
  Ctrl+Up, Ctrl+Down  history
  PgUp, PgDn          scroll

Tree
  Up, Down, Left, Right   move
  Enter, Space            open or close

Mouse
  click, wheel and scroll bars in the tree, the editor and the console;
  a middle click on a window title closes it
