## Highlights

This is the **first alpha release** of Eve: a preview to try the language and report problems, not a stable version. Scripts and options can still change between releases.

- **Two platforms.** One archive for Windows x64 (`eve-0.0.8-windows-x64.zip`) and one for Linux x64 with glibc (`eve-0.0.8-linux-x64.tar.gz`), each with `eve`, `evevm`, `evecp`, `evedb` with the DuckDB library, `evetx`, `eveux`, the standard library and this manual. `SHA256SUMS.txt` holds the checksums of both.
- **The core language is validated** at levels 1 and 2: script shapes, declarations, expressions, control flow, jobs and error recovery, types, collections, strings, functions and serial aspects (`F-LNG-01` to `F-LNG-09`, `F-STR-02`), command-line parameters and configuration files (`F-STR-05`, `F-STR-06`).
- **Structure and concurrency are validated** for the main cases: classes and modules (`F-LNG-10`, `F-STR-01`), parallel aspects, channels, tasks, deadlines and cancellation (`F-MTK-01`, `F-MTK-03` to `F-MTK-05`), generics, overloading and generators (`F-LNG-20`, `F-LNG-21`, `F-LNG-12`).
- **Two engines.** The tree walker is the reference; the bytecode machine (`--engine bc`) runs the same 457 tests with the same results (`F-VM-13`).
- **The data layer is drafted** (level 5): record-table mapping is validated (`F-DAT-11`), most of the rest of the database layer is partial; the machine with its doors (level 6) and the server `evedb` (level 7) are early drafts.

## Decisions

This is the first release, so every decision up to D-214 applies. The last ones, settled on 2026-10-21:

- `D-206` Only the primary aspect starts concurrent aspects.
- `D-207` A function, a procedure and a method can have a `recover` region.
- `D-208` The HTTP client is level 5, the server level 6.
- `D-209` A template is a text with `{var}`, no loops.
- `D-210` `read(prompt)` gives `String?`, `null` at the end of the input.
- `D-211` The names of the console and of the exceptions are built in at level 1.
- `D-212` `-p name=value` and the help made from `** @param` comments.
- `D-213` A loop has one scope: a `new` in the body fails at the second cycle.
- `D-214` The layout and the rules of the libraries.

## Breaking changes and migration

None: this is the first release. One rule of this release changes scripts written against earlier development builds: a `new` declaration inside a loop body now fails at the second cycle (`D-213`); declare the variable before the loop and assign it in the body.

## Known issues

- No test fails: 457 of 457 conformance and smoke tests pass on the tree walker and on the bytecode machine (Windows, ReleaseSafe build).
- **Linux is cross-compiled** from Windows and checked with the smoke tests (21 of 21) on Ubuntu 24.04; the full suite runs on Linux in continuous integration only. Report what breaks on other distributions.
- **Drafted features are partial**: 45 of 144 features are drafted, among them the exception module (`F-LIB-02`) and the system variables (`F-STR-07`) at level 1; the page of each feature lists what is missing ([features](../features.md)).
- **`eveux`**, the graphical workbench, is an early draft; `evetx`, the terminal IDE, has no automated tests.
- **The benchmarks of this release were measured on a busy machine** (see Performance); they are not a regression.

## Performance

<!-- GEN:performance (script/relnotes.py) -->
Total median time of the benchmarks of each level, ReleaseSafe build, run of 2026-10-21 21:45 (commit `43003a9`), against the twins in Python and against version 0.0.7 (2026-10-19). Every benchmark: [performance report](../performance.md).

| Benchmarks | Eve | Python | Eve / Python | Change |
|---|---|---|---|---|
| Level 1 | 248 ms | 313 ms | 0.8x | +79% (slower) |
| Level 2 | 165 ms | 190 ms | 0.9x | +82% (slower) |
| Level 3 | 322 ms | 202 ms | 1.6x | +128% (slower) |
| Level 4 | 930 ms | 1394 ms | 0.7x | +69% (slower) |
| Level 5 | 131 ms | 240 ms | 0.5x | +64% (slower) |
| Level 6 | 2467 ms | - | - | +7% (slower) |
<!-- /GEN:performance -->

The run saved for this release is 64% to 128% slower than the 0.0.7 run for levels 1 to 5, because the machine was busy (71% CPU from other programs). Run side by side under the same load, 0.0.8 and the 0.0.7 build are within 0% to 5% of each other (`p1a_arith` 103.9 against 103.2 ms, `p1b_calls` 68.8 against 65.6 ms): the one scope per loop of `D-213` and the built-in list, map and string functions cost no measurable time. `eve` grows 3.6%, to 4,199 KB, with those functions.
